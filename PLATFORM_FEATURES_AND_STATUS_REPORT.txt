1. **EXECUTIVE SYSTEM ARCHITECTURE**
================================================================================
[**Client Layer**]
  - **Framework**: **Next.js 16** (React 19, TypeScript)
  - **Strategy** : **SSR-First** (React Server Components by default; Client Components
                   strictly for interactive state and event handlers)
  - **Data Sync**: Centralized typed API Client with **Axios & GraphQL**

[**API Gateway Layer**]
  - **Framework**: **NestJS 11** (TypeScript, Node.js ESM)
  - **Security** : **Passport.js JWT Auth**, **Role-Based Access Control (RBAC)**,
                   **CollegeAccessGuard** for multi-tenant data isolation

[**Data & Worker Layer**]
  - **Database** : **PostgreSQL with Prisma ORM**
  - **Queue**    : **Redis & BullMQ** for asynchronous code execution and mail outbox
  - **Sandbox**  : **Docker Sandbox / Judge0 CE** supporting C++, Java, Python, Go,
                   Rust, C, JavaScript, and TypeScript

2. **ROLE-WISE FEATURE BREAKDOWN**
================================================================================

--------------------------------------------------------------------------------
2.1. **SUPER ADMIN & PLATFORM ADMIN (SUPER_ADMIN, PLATFORM_ADMIN)**
--------------------------------------------------------------------------------
Responsible for global platform governance, multi-tenant monitoring, system
health diagnostics, and global problem curation.

* **Platform Control Dashboard (/superadmin)**:
  - Real-time submission activity telemetry and system velocity metrics.
  - Live diagnostics for database replication, Redis queue throughput, and
    judge execution workers.
  - **Endpoint**: GraphQL **ADMIN_METRICS_QUERY**

* **Institution & College Management (/superadmin/institutions, /superadmin/colleges)**:
  - Complete CRUD for institutions and universities.
  - Multi-tenant domain binding, subscription tier management, and college deans.
  - **Endpoint**: REST **GET/POST/PATCH/DELETE /colleges**

* **Platform Problem Bank (/superadmin/problems)**:
  - Problem statement authoring with Markdown, math equations, and example IO.
  - Test case management (public sample tests vs hidden evaluation test cases).
  - Time limits (ms), memory limits (MB), topic tagging, and difficulty grading.
  - **Endpoint**: REST **/problems**

* **Problem of the Day (POTD) Scheduler**:
  - Calendar-based scheduling of daily challenges with custom bonus points.
  - Multi-tier persistence (**PostgreSQL database -> Redis -> memory fallback**).
  - **Endpoint**: **POST /problems/potd/set**

* **User Directory & Role Promotion (/superadmin/users)**:
  - Global user search, role escalation, credential sanitization, and audit logs.
  - **Endpoint**: REST **/users**, GraphQL **USERS_QUERY**


--------------------------------------------------------------------------------
2.2. **INSTITUTION ADMIN & COLLEGE DEAN (INSTITUTION_ADMIN, COLLEGE_ADMIN)**
--------------------------------------------------------------------------------
Responsible for college campus operations, student cohorts, faculty assignments,
and institutional performance tracking.

* **Campus Analytics & Performance (/institution-admin/analytics)**:
  - College-level solve counts, active student engagement velocity, and
    batch-by-batch comparative analytics.

* **Batch & Cohort Management (/institution-admin/batches)**:
  - Creation and roster management for student batches (e.g., **"Batch 2026 CS-A"**).
  - Graduation year tracking, student capacity, and batch status controls.
  - **Endpoint**: REST **/batches**

* **Student Roster & Single/Bulk Invitations (/institution-admin/students)**:
  - Single student invitations and bulk CSV roster imports.
  - Automated invitation email dispatch with single-use activation tokens.
  - CSV export protected against formula injection payloads (**sanitizeCsvField**).
  - **Endpoint**: **POST /users/bulk-invite**, **POST /auth/accept-invitation**

* **Faculty Department Allocation (/institution-admin/faculty)**:
  - Faculty onboarding and department/course assignment.
  - **Endpoint**: **POST /colleges/:id/members**

* **College Data Isolation**:
  - Guaranteed data boundary isolation enforced by **CollegeAccessGuard**.


--------------------------------------------------------------------------------
2.3. **FACULTY, INSTRUCTORS & MENTORS (FACULTY)**
--------------------------------------------------------------------------------
Responsible for curriculum delivery, interactive programming assignments,
student evaluation, and contest organization.

* **Curriculum & Course Management (/courses, /superadmin/courses)**:
  - Multi-module course builder with video/text lessons and progress tracking.
  - Mandatory coding assignments linked to course milestones.
  - **Endpoint**: REST **/courses**

* **Campus-Exclusive Problem Authoring (/problems/create)**:
  - Authoring private college problems visible only to enrolled students.
  - Test case verification and custom constraint configuration.
  - **Endpoint**: **POST /problems**

* **Contest Hosting & Management (/contests)**:
  - Hosting private and college-wide competitive programming contests.
  - Time-locked problem statements with automated release upon contest start.
  - **Endpoint**: REST **/contests**

* **Automated Plagiarism Detection**:
  - Tokenized AST and pairwise similarity analysis across student submissions.
  - **Service**: **PlagiarismService**


--------------------------------------------------------------------------------
2.4. **STUDENTS & COMPETITIVE PROGRAMMERS (STUDENT)** — **CODECHEF STYLE ARENA**
--------------------------------------------------------------------------------
End-users engaging in problem solving, daily streak challenges, contests, and
verified industry skill tracking.

* **Interactive Problem Solving Workspace (/problems/[slug])**:
  - Split-pane interface: Problem statement, custom test runner, and submission log.
  - Multi-language code editor supporting **C++, Java, Python, Go, Rust, and TS**.
  - Real-time compiler telemetry (stdout, stderr, execution time ms, memory MB).
  - **Service**: **CompilerService** (Judge0 Sandbox integration)

* **Structured Problem Archive (/problems)**:
  - High-density list-table directory with search, difficulty (**Easy / Medium / Hard**),
    topic tags, and solved/attempted status indicators.
  - Secure CSV dataset export with CSV-injection protection.
  - **Component**: **ProblemArchiveClient**

* **Daily Problem of the Day & Streak Multiplier**:
  - Daily challenge with streak bonus points (**1.0x to 2.5x multiplier**).
  - 60-day interactive activity calendar heatmap.
  - **Endpoints**: **GET /problems/potd/today**, **GET /problems/user/streak**

* **Competitive Contests Arena (/contests) — CodeChef Contest Structure**:
  - **CodeChef Style Multi-Division System**: Live **Division 1 (Pro)**, **Division 2 (Intermediate)**,
    and **Division 3 (Beginner)** contest participation with dynamic countdowns.
  - Real-time leaderboard score calculation incorporating penalty time and runtimes.

* **Live Ratings & Global Leaderboard (/leaderboard) — CodeChef Star Ratings**:
  - **CodeChef Dynamic Star Tiers**: Student performance mapped to authentic **CodeChef Star Ratings**:
    * **1-Star (★)** : 0 – 1399
    * **2-Star (★★)** : 1400 – 1599
    * **3-Star (★★★)** : 1600 – 1799
    * **4-Star (★★★★)** : 1800 – 1999
    * **5-Star (★★★★★)** : 2000 – 2199
    * **6-Star (★★★★★★)** : 2200 – 2499
    * **7-Star (★★★★★★★)** : 2500+
  - **College vs. College Comparative Rankings**: Institutional league tables.
  - Neutral rank representation for unranked profiles (**—**).
  - **Component**: **RatingHistoryChart**

* **Verified Industry Skill Passport (/students/skill-passport)**:
  - Cryptographically verifiable transcript with dynamic QR code verification.
  - Automated ledger tracking verified GitHub PRs, CI/CD pass rates, and Jira points.
  - 1-Click Cloud Web IDE workspace URL with distinct user tenant ID.
  - **Component**: **SkillPassportClient**

* **Student Profile & Security (/students/profile)**:
  - Solved problem breakdown by difficulty, rating progression graph, and
    two-factor authentication credentials.

3. **SUMMARY OF COMPLETED ENGINEERING WORK & VERIFICATION**
================================================================================

3.1. **Backend Architecture & Services (/server)**:
--------------------------------------------------
* **Database Query Deduplication**:
  - Upgraded accepted-submissions query in **UsersService** to perform database-level
    grouping/distinct operations rather than in-memory processing.
* **Multi-Tier POTD Persistence**:
  - Implemented database-backed persistence (**prisma.problemOfTheDay**) with
    Redis hash caching and fallback memory maps.
* **Multi-Tenant Security**:
  - Enforced **CollegeAccessGuard** and **RolesGuard** across institutional endpoints.
* **Mail Outbox & Sanitization**:
  - Integrated SMTP/Mailgun transport with outbox logging and activation link
    sanitization.

3.2. **Frontend Modernization & Real API Integration (/client)**:
----------------------------------------------------------------
* **Full Mock Data Removal**:
  - Replaced legacy static mocks with live backend endpoints via typed
    **apiService** using **Axios and GraphQL**.
  - Bound student streaks, profile metrics, heatmaps, and problem archives to live DB.
* **List-Table Presentation Standard**:
  - Refactored problems, contests, and student rosters into high-density
    list-table layouts with pagination and filtering.
* **Formula Injection Protection**:
  - Implemented **sanitizeCsvField** across all tabular exports.

3.3. **Hardening & Bug Fixes**:
-------------------------------
* **SkillOS Workspace Auth Route (/api/skillos/workspace)**:
  - Differentiated **401 (invalid credentials)** from **502/503 (upstream server/transport errors)**.
  - Ensured stable unique **corporateId** strings for isolated Cloud IDE sandboxes.
* **Skill Passport QR Generator**:
  - Guarded **QRCode.toDataURL** against async race conditions with cancellation flags (**isCancelled**).
  - Applied **encodeURIComponent(corporateId)** to verification links.
* **Rating History Graph**:
  - Replaced artificial rank defaults with neutral **"—"** representation.
